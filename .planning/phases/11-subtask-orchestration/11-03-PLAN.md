<objective>
Build the streaming subtask runner that replaces the fire-and-forget `ScriptRunner` for the orchestration path. It spawns a `Process` per subtask, drains stdout and stderr concurrently via `FileHandle.readabilityHandler` into an `AsyncStream<SubtaskEvent>`, classifies `EXMEN:` lines as hook events, enforces a per-subtask timeout, and kills the child's entire process group on timeout/cancel so no zombies survive (ORCH-06).

Purpose: Live per-subtask progress (ORCH-03) and dynamic spawn (ORCH-04) both require line-by-line streaming, which `ScriptRunner` cannot provide. Clean process-group teardown is the ORCH-06 zombie guarantee.
Output: `SubtaskRunner.swift` + `SubtaskEvent` enum, exercised by `TimeoutTests`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| subtask script → /bin/bash child process | User-authored script content executed via bash -c; same trust level as existing action scripts |
| child stdout/stderr → AsyncStream events | Untrusted-shaped bytes (incl. EXMEN: lines) cross into the parser; classification is purely structural here |
| timeout/cancel → OS process group | Signal delivery to a negative PID affects the whole group |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-06Z | Elevation/DoS (zombies) | timeout/cancel teardown | mitigate | `kill(-pid, SIGTERM)` then `kill(-pid, SIGKILL)` after 5s reaches the whole process group (Foundation.Process sets POSIX_SPAWN_SETPGROUP); verified by TimeoutTests + the manual zombie check in 11-VALIDATION. |
| T-11-DLK | DoS (pipe deadlock) | concurrent stdout/stderr drain | mitigate | `readabilityHandler` on BOTH pipes (never `readDataToEndOfFile` on a running process) — Pitfall 1. |
| T-11-EOF | DoS (hung stream) | stderr EOF not delivered (SR-12080) | mitigate | Drain residual + finish in `terminationHandler`, which is always called — Pitfall 2. |
| T-11-SC | Tampering | npm/pip/cargo installs | accept | No package-manager installs; RESEARCH Package Legitimacy Audit confirms zero new dependencies. |
</threat_model>
