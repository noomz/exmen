<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| EXMEN:subtask= raw value → spawnDynamic decode | Untrusted-shaped string from a child script; decode can throw, must not crash the run |
| runtime spawn loop → orchestrator state | A script re-emitting subtasks could attempt unbounded growth |
| concurrent subtask Tasks → @MainActor @Published state | Reentrancy across await points could corrupt subtaskStates |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-DoS | DoS | unbounded dynamic spawn | mitigate | `maxSubtaskCount` guard (50) in `run` and `spawnDynamic`; duplicate-id idempotent ignore (D-08) blocks re-emit loops. |
| T-11-V5d | Tampering (V5 Input Validation) | `spawnDynamic` decode | mitigate | `try? SubtaskConfig.decodeInlineTable` — malformed, both-cmd-and-script, or neither-present inline table is logged and ignored, never crashes (D-02a); unknown `depends_on` fails only that subtask (D-07). |
| T-11-RNT | Tampering | actor reentrancy corrupting state | mitigate | All `@Published` mutations are synchronous (no await between read and write) per Pitfall 4. |
| T-11-SC | Tampering | npm/pip/cargo installs | accept | No package-manager installs; RESEARCH Package Legitimacy Audit confirms zero new dependencies. |
</threat_model>
