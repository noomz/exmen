<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| TOML config file → SubtaskConfig decode | User-authored static config; same trust as existing action TOML |
| EXMEN:subtask= inline table → decodeInlineTable | Child-process stdout (user controls the script); untrusted-shaped string crosses into TOMLDecoder |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-V5 | Tampering (V5 Input Validation) | `SubtaskConfig.decodeInlineTable` | mitigate | Wrap-and-decode through TOMLDecoder which enforces TOML grammar (no newline in inline table, no trailing comma); malformed input throws and is caught by the caller (plan 11-05) rather than crashing. A missing required `id` fails decode. |
| T-11-A1 | Spoofing | duplicate/invalid subtask id | accept | id uniqueness/idempotency is enforced by the orchestrator (D-08, plan 11-05), not the model; model stays a pure value type. |
| T-11-SC | Tampering | npm/pip/cargo installs | accept | No package-manager installs; RESEARCH Package Legitimacy Audit confirms zero new dependencies. |
</threat_model>
