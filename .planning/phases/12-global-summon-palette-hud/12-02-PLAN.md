  <action>
Wrap `InstallEventHandler`, `RegisterEventHotKey`, and `UnregisterEventHotKey` in a lifecycle-safe manager. Install one application-hot-key handler, distinguish Exmen's signature/id from unrelated events, dispatch its callback to the main actor, and unregister on replacement/deinit.

If Carbon returns a collision or another OSStatus, preserve/re-register the previous shortcut and return a descriptive error for Settings. Inject a small registration backend in tests so conflict, rollback, repeated replacement, and cleanup are exercised without taking over a developer's real keyboard.
